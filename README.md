# Stay Nola Lofts

This repository contains the static website for Stay Nola Lofts, built as a single-page landing site intended for GitHub Pages or similar static hosting.

## Local preview

Open `index.html` in a browser or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Custom domain

A `CNAME` file is included for `staynolalofts.com`.

## Publishing to GitHub Pages

1. In the GitHub repo, go to Settings > Pages.
2. Set source to the default branch.
3. If using a custom domain, add the custom domain in GitHub Pages settings and configure your DNS record at the domain registrar.
